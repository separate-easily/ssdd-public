# 🚀 5분 만에 시작하기

## 1단계: 프로젝트 이해하기 (1분)

**쏙쏙분리 똑똑분리**는 어린이 분리수거 교육 게임입니다.

- 👨‍💼 **관리자** (데스크톱): QR 코드 생성, 아동 등록, 게임 진행
- 👶 **일반 사용자** (모바일): 간단한 게임, 순위 확인

---

## 2단계: 로그인하기 (1분)

### 선생님(기관) 로그인
- 처음 사용 시: [회원가입] 버튼을 눌러 기관 계정 생성
- 로그인: 생성한 계정으로 로그인

### 일반 사용자
- 회원가입 후 로그인


---

## 3단계: 핵심 파일 알아두기 (2분)

### ⭐ 자주 수정하는 파일 2개만 기억하세요!

#### 1. 백엔드 (API)
```
/supabase/functions/server/index.tsx
```
→ 모든 API가 여기 있음

#### 2. 관리자 화면 (QR 생성 포함)
```
/src/app/components/AdminDashboard.tsx
```
→ QR 생성, 기관 관리, 게임 진행

---

## 4단계: QR 코드 생성하기 (1분)

1. 관리자 로그인
2. "QR 코드 생성" 버튼 클릭
3. 시작: 1, 끝: 50 입력
4. "QR 코드 생성하기" 클릭
5. "전체 다운로드" 클릭

→ 50개의 QR 코드 완성! 🎉
